#  Egg Boiling Guide App

A simple and friendly **PyQt5 desktop application** that helps you boil eggs perfectly every time.  
The app provides a visual and interactive timer based on your preferred egg type (soft, medium, or hard-boiled).

---

##  Features

-  Choose between **soft**, **medium**, or **hard** boiled egg.
-  Built-in **timer** that guides you step-by-step.
-  Clean and intuitive **PyQt5 interface** .
-  Lightweight and runs locally — no installation required.

---

##  Requirements :

- Make sure you have Python 3 installed
- install PyQt5 library
